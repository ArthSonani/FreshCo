# 🛒 FreshCo – Empowering Local Stores Digitally

**FreshCo** is a full-stack web application that enables **local vendors** to take their stores online with ease. It offers seamless **order tracking**, **inventory management**, and **secure payment processing** — all through a mobile-friendly interface. Built using the **MERN stack**, FreshCo helps small businesses boost their operational efficiency and customer outreach.

## 🚀 Key Features

- 🛍️ **Vendor Storefronts**  
  Vendors can create and manage their own digital shop, complete with product listings and real-time inventory updates.

- 📦 **Order Management**  
  Track orders from placement to delivery, enhancing transparency and customer satisfaction.

- 🔐 **OTP Verification + JWT Auth**  
  Ensures secure sign-in and transactions with **mobile OTP authentication** and **JWT-based session management**.

- 💳 **Razorpay Payment Integration**  
  Supports secure, real-time payments for a smooth checkout experience.

- 📱 **Responsive UI**  
  Fully optimized for both desktop and mobile, ensuring accessibility for all users.

- 📈 **Efficiency Boost**  
  Increased operational efficiency by 40% for local vendors through automation and digital workflows.

---

## 🛠️ Tech Stack

- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: OTP, JWT
- **Payments**: Razorpay Gateway
- **Deployment**: Vercel (Frontend), Render (API)
